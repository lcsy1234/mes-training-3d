# MES 工厂实训室 v0.2.1

[在线体验](https://lcsy1234.github.io/mes-training-3d/) · [基础演示](https://lcsy1234.github.io/mes-training-3d/basic.html)

面向新人的饮料工厂教学场景。进入剖面全景，点击八个区域进入工位特写；完成前处理实训，理解实物、任务、标签与数量的联系。

## 三个入口

- **工厂全景**：计划中控、仓储交接、脱包、整包备料、小料称量、整桶汇集、工艺投料、杀菌至后包。后段可展开设备说明、播放管路和瓶体流转。
- **前处理实训**：签收→原料脱包→原料备料（整包／分称）→汇集与前处理投料，四章连续操作。
- **按包练习**：三份50kg任务、每包25kg，产生六张标签，任务仍为三份。
- **基础演示**：原签收100kg、称量75kg、投料70kg、退料30kg的独立演练继续可用。

## 四章操作

1. 核对产程 DEMO-P01、批次 DEMO-A 并签收。
2. **先脱包**：去除外包装，保留内包装或放入洁净周转容器，生成脱包码。77kg大料、小料、茶叶为本课必需来源，20kg对照来源可选脱包。每个脱包码须打印、核对贴附，才能进入备料。
3. **再备料**：整包和小料分称同属备料阶段，可以分别操作。扫描77kg的脱包码，按桶完成3份25kg，脱包来源余2kg。20kg对照来源若参与不足练习，应先脱包；不足不会完成任务或扣料。未使用的RAW-20保持20kg。
4. 小料在本章去皮、加减料、稳定称量：毛重0.60kg、皮重0.10kg、净重0.50kg，稳定1秒后确认，分别完成三桶。茶叶教学备料也在本章生成三份1kg标签。所有备料标签均打印、贴标后才可继续。
5. **备料完成后再汇集投料**：按任务桶号归集三项物料，再大料D-01溶解、茶叶E-01萃取，随后小料M-01调配。错误桶号、漏料、错误设备与重复投料均被拦截。
6. 任一阶段业务成功后均可模拟缺纸并补打原标签；补打不新增库存、不再次完成业务。

脱包属于原料准备环节，不是称量或设备投料；整包不意味着带外包装投料。本课按用户提供的流程图先脱包，并不据此断言所有现场物料一律必须脱包。实际MES允许哪些来源类型应与本课顺序区分。

完整教学演练：签收105kg＝已投79.5kg＋现场余额25.5kg；余额包含独立20kg来源、77kg来源剩余2kg、小料脱包剩余3.5kg。所有称量、茶叶重量及稳定参数均为教学设置，不构成饮料配方或现场操作标准。

## 数据与追溯

重量以整数克存储。来源码、子标签、任务、打印作业、料车和投料记录分别管理。转换将父码余额转到子码，只有投料才进入耗用账。每次操作先校验并更新模拟数据，再播放动画；动画不改数量。

点击实物或标签“查看来源链”可查看原料码→脱包码→整包码／称量码。三条摘要同时说明实物位置、任务进度与数量账；记录可导出JSON。视角和课程切换保留各自本轮进度，刷新或重新演练会重置。

生产任务桶号、搬运容器、大型生产调配桶分别表达。整包与称量为独立支路。虚拟仓只作账务说明。W0470仅为资料中特定案例，不实现通用免签收。未核实拆码协议及历史系统规划不作为本课确定规则。

## 本地运行与校验

需要 Node.js20.19+或22.12+。

```bash
npm ci --registry=https://registry.npmjs.org
npm run dev
npm test
npm audit --registry=https://registry.npmjs.org --audit-level=high
BASE_PATH=/mes-training-3d/ npm run build
npm run preview
```

`index.html`与`basic.html`是两个Vite构建入口。静态模型直接来自`model-library/`，程序路径使用`import.meta.env.BASE_URL`。修改静态目录配置后请重启开发服务器。

## 发布与边界

推送main后，GitHub Actions执行测试、依赖审计、双入口构建并发布GitHub Pages。PR仅执行检查。回退通过git revert后重新推送完成。

教学布局不复刻实际工厂平面。本版本无后端，无MES写入，不连接PLC、真实打印机、秤、仓储或财务。扫码用模拟标签选择，管路流向为教学示意；实际产品应另行核实工艺路线、参数、拆码协议与仓库例外。
