# MES 车间实训室

本地新人培训应用。使用 Tripo 实际生成的 GLB 模型，可点击实体、旋转/缩放场景，按顺序练习签收、称量、投料、退料。只使用教学模拟数据，未连接真实 MES。

## 启动

双击上一级目录的 `启动培训.command`；或在此目录执行：

```bash
npm install
npm run dev -- --port 5178
```

浏览器打开 http://127.0.0.1:5178/ 。如端口被占用，以终端打印的地址为准。刷新页面会开始一轮新演练；关闭前可以导出 JSON 演练记录。

## 本轮演练

1. 签收：选择托盘，核对 A 批次，签收 100kg。错误批次会拦截。
2. 称量：选择称量工位，将示数 74 改为 75kg，确认称量并生成模拟标签。
3. 投料：选择 T-01，核对 A 批次、T-01，投料 70kg。可以尝试 B 批次或 T-02，观察拦截。
4. 退料：将托盘余料 25kg 和桶内剩余 5kg 一起退回，共 30kg。

完成后核对 100＝70＋30。操作记录、三条线说明和数量账同步更新。支持重新开始、操作说明、俯视/全景切换，以及键盘使用实体名称按钮。

本演练固定的称量值、数量和动作次序是教学场景规则，不能作为真实现场的容差、审批、WMS 或金蝶处理规则。投料扫码为下拉选择模拟，不接实体扫码枪。模拟标签仅用于教学。任务记录显示成功不代表外部系统回传成功。
